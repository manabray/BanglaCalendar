# বাংলা ক্যালেন্ডার | Bangla Calendar

Windows-এর জন্য একটি বিনামূল্যের, ওপেন-সোর্স বাংলা ক্যালেন্ডার। বাংলাদেশের সংশোধিত বাংলা বর্ষপঞ্জি অনুযায়ী বাংলা মাস, বঙ্গাব্দ এবং বাংলা ও গ্রেগরিয়ান তারিখ পাশাপাশি দেখায়।

**সংস্করণ:** 0.1.0 · **লাইসেন্স:** MIT

## বৈশিষ্ট্য
- বাংলা মাস, বাংলা সাল ও বাংলা অঙ্ক
- প্রতিটি দিনের সঙ্গে গ্রেগরিয়ান তারিখ
- আগের মাস, পরের মাস ও আজকের তারিখে ফেরার সুবিধা
- ডিজিটাল ঘড়ি ও আজকের বাংলা তারিখ পাশাপাশি; সময়ের উৎসের বার্তা শুধু ঘড়ির ওপর মাউস রাখলে দেখায়
- বাংলা মাস অনুযায়ী ছয় ঋতুর নাম ও সংক্ষিপ্ত পরিচিতি
- পোস্টার-অনুপ্রাণিত দুই-কলামের ডিজাইন: বাম পাশে ঋতু, ঘড়ি ও নির্বাচিত দিনের ছুটির সার-সংক্ষেপ; ডান পাশে ক্যালেন্ডার
- ক্যালেন্ডারে সব ৪২টি ঘর সমানভাবে আঁকা হয়; ছুটির দিন উচ্চ-কনট্রাস্ট ব্যাজে চিহ্নিত থাকে
- অফলাইনে কাজ করে; অতিরিক্ত runtime dependency নেই
- GitHub Actions-এ স্বয়ংক্রিয় পরীক্ষা ও Windows EXE build

## Windows-এ চালানো
Python 3.10+ ইনস্টল করে প্রকল্প ফোল্ডার থেকে চালান:

```powershell
python bangla_calendar.py
```

Windows EXE বানাতে `build_windows.bat` ফাইলে ডাবল-ক্লিক করুন। অথবা GitHub Actions চালিয়ে `BanglaCalendar.exe` artifact ডাউনলোড করুন।

## রঙের থিম
অ্যাপের ব্র্যান্ড রঙ তিনটি: গাঢ় নীল `#00578E`, নীল `#0084C8` এবং উজ্জ্বল সায়ান `#00BBFF`। পঠনযোগ্যতার জন্য সাদা ও হালকা নীলাভ নিরপেক্ষ ব্যাকগ্রাউন্ডও ব্যবহার করা হয়েছে।

## সরকারি ছুটির তালিকা ও সার-সংক্ষেপ
- ক্যালেন্ডারের তারিখে ছুটি থাকলে হালকা নীল রঙ ও “ছুটি” চিহ্ন দেখায়।
- তারিখ নির্বাচন করলে ছুটির নাম, ধরন, সংক্ষিপ্ত বিবরণ এবং সংশ্লিষ্ট উইকিপিডিয়া নিবন্ধের লিংক দেখায়।
- **২০২৬ সালের** সাধারণ ও নির্বাচিত ঐচ্ছিক/নির্বাহী-আদেশের ছুটির তালিকা জনপ্রশাসন মন্ত্রণালয়ের প্রকাশিত ছুটির প্রজ্ঞাপন অনুযায়ী সাজানো হয়েছে: [সরকারি প্রজ্ঞাপন](https://mopa.gov.bd/pages/public-holiday/%E0%A7%A8%E0%A7%A6%E0%A7%A8%E0%A7%AC-%E0%A6%96%E0%A7%8D%E0%A6%B0%E0%A6%BF%E0%A6%B7%E0%A7%8D%E0%A6%9F%E0%A6%BE%E0%A6%AC%E0%A7%8D%E0%A6%A6%E0%A7%87%E0%A6%B0-%E0%A6%9B%E0%A7%81%E0%A6%9F%E0%A6%BF%E0%A6%B0-%E0%A6%A4%E0%A6%BE%E0%A6%B2%E0%A6%BF%E0%A6%95%E0%A6%BE%E0%A6%B0-%E0%A6%AA%E0%A7%8D%E0%A6%B0%E0%A6%9C%E0%A7%8D%E0%A6%9E%E0%A6%BE%E0%A6%AA%E0%A6%A8-2df487-694139b2a31054345f0e6346)।
- অন্য বছরে পরবর্তী সরকারি বর্ষপঞ্জি যোগ না করা পর্যন্ত শুধু নির্দিষ্ট গ্রেগরিয়ান তারিখের পুনরাবৃত্ত ছুটি দেখানো হয়। ধর্মীয় ছুটির তারিখ চাঁদ দেখা/পরবর্তী প্রজ্ঞাপনের কারণে বদলাতে পারে।
- ছুটির বিবরণগুলি সংশ্লিষ্ট [উইকিপিডিয়া নিবন্ধগুলোর](https://en.wikipedia.org/wiki/Public_holidays_in_Bangladesh) ভিত্তিতে বাংলায় সংক্ষিপ্তভাবে পুনর্লিখিত; অ্যাপ ইন্টারনেট ছাড়াই সংরক্ষিত সার-সংক্ষেপ দেখায় এবং লিংকে ক্লিক করলে পূর্ণ নিবন্ধ খোলে।

### তথ্যসূত্র ও লাইসেন্স
ক্যালেন্ডারের প্রোগ্রাম কোড MIT লাইসেন্সের আওতায়। `holidays.py`-এর উইকিপিডিয়া-ভিত্তিক সার-সংক্ষেপগুলো সংশ্লিষ্ট নিবন্ধের লিংকসহ পৃথকভাবে অ্যাট্রিবিউট করা হয়েছে; এগুলো CC BY-SA লাইসেন্সের শর্ত অনুযায়ী পুনর্ব্যবহারযোগ্য। সরকারি তারিখের প্রাথমিক উৎস জনপ্রশাসন মন্ত্রণালয়ের প্রজ্ঞাপন, উইকিপিডিয়া নয়।

## বাংলা তারিখের নিয়ম
বাংলাদেশের সংশোধিত বাংলা বর্ষপঞ্জি অনুসরণ করা হয়: পহেলা বৈশাখ ১৪ এপ্রিল; বৈশাখ–আশ্বিন ৩১ দিন; পরবর্তী পাঁচ মাস ৩০ দিন; ফাল্গুনে সাধারণ বছরে ২৯ এবং প্রাসঙ্গিক গ্রেগরিয়ান অধিবর্ষে ৩০ দিন। এই সংস্করণ ঐতিহাসিক পঞ্জিকা মিলানোর বিকল্প নয়। সরকারি ছুটির তালিকা উপরের বিভাগে বর্ণিত সীমা অনুযায়ী যুক্ত করা হয়েছে।
